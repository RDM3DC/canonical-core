# Glossary

Definitions of all key terms and symbols in Canonical Core.

---

## A

**Adaptive Impedance Network (AIN)**  
A network where impedance (resistance + reactance) adapts to strain and memory. Defined in Paper 01.

**Adaptive Resistance Pattern (ARP)**  
A pattern of resistance that changes in response to strain. Defined in Paper 01.

**Adaptive-π (πₐ)**  
A version of π that is not constant (3.14159...) but instead varies with context as a geometric field. Defined in Paper 02.

---

## C

**Coherence Time (τ_coh)**  
The time scale over which phase coherence is maintained. Defined in Paper 05.

**Curve Memory (CM)**  
A memory object that encodes both the path history and derivative history of a system. Defined in Paper 03.

**Curve Memory Alphabet (CMA)**  
The encoding system (alphabet) used to represent Curve Memory. Defined in Paper 03.

---

## P

**Phase-Lift (⧉)**  
A prefix operator that creates phase-structured branches. Syntax: `⧉(state, context)`. Defined in Paper 04.

**Phase-Resistant Objects (PROs)**  
Objects that carry properties across phase transitions without losing coherence. Defined in Paper 04.

**PR-Root**  
The root of a phase-structured tree; the origin point for Phase-Lift branches. Defined in Paper 04.

---

## Q

**Quantum Phase Space (QPS)**  
Phase space with quantum structure (non-commutative, with ℏ). Defined in Paper 05.

**QPS-GR Mapping**  
The engineering layer that maps Quantum Phase Space to General Relativity, with explicit assumptions about strain, clocks, and visibility. Defined in Paper 05.

---

## S

**Strain Parameter (ε_strain)**  
A dimensionless parameter representing geometric strain in QPS-GR mapping. Defined in Paper 05.

---

## T

**τ_coh** – See **Coherence Time**

---

## V

**Visibility Floor (V_floor)**  
The minimum detectable visibility in QPS-GR mapping. Below this threshold, phase information is lost. Defined in Paper 05.
